## Risks and mitigations

| Risk | Mitigation (task) |
|---|---|
| Full 16-digit `product_number` leaks into a model, log or prompt (R5 gap is open, D2) | FakeBank selects only `right(product_number, 4)`; the full number never leaves SQL (T5). Fixture numbers are obviously fake (`000000000000NNNN`) (T5) |
| DuckDB auto-detect types differ across 1097 transaction files (`response_code` `00` → `0`) | Read CSVs with `all_varchar=true` and cast in SQL; `hive_partitioning`, `union_by_name` (T5) |
| Fixture has no BOM while `data/` does, so tests pass and the sandbox breaks | Fixture CSVs are written with a UTF-8 BOM like the raw files (T5) |
| DuckDB is blocking I/O inside async nodes (`06` §4) | FakeBank methods wrap queries in `asyncio.to_thread` (T5) |
| import-linter forbidden contract trips on the legal chain `app.domains.conversation → app.core.llm → langchain_anthropic` | `allow_indirect_imports = True` on the domains contract; `include_external_packages = True` (T1). The `app.core` contract uses `ignore_imports` for `app.core.llm.**` and is added in T3 once `app.core.llm` exists, so no unmatched-ignore error (T3) |
| import-linter contract naming a module that doesn't exist (`app.api`, bank `repository` modules) errors | Only contracts over existing modules today; note the missing ones in the state file for A3 to add (T1) |
| `ChatBedrockConverse` has no `max_retries`/`timeout` kwargs and needs a region at construction | Build it with a botocore `Config(retries={"max_attempts": 3}, read_timeout=20, connect_timeout=...)` and `region_name` from settings; the test sets `AWS_REGION` and never calls the network (T3) |
| mypy strict on `app.core.*`/`conversation.*` fights langgraph/langchain generics; babel lacks stubs | `babel.*` override + `types-PyYAML` (T1); targeted `# type: ignore[code]` only, no loosening of the overrides (T3, T11) |
| Provider exceptions escape as LangChain/SDK types (D5 d) | Wrapper maps `anthropic.APIError` family and botocore errors to `LLMUnavailable`; returns only the Pydantic object (T3) |
| Prompt/output text lands in logs | `llm.call` has a fixed field set; T3's test asserts the event keys and that the user text is absent |
| `trace_id` is required in `llm.call` but `structured()` has no parameter for it (surface is Ask-first) | Wrapper reads `trace_id` from `structlog.contextvars`; sandbox/graph bind it per turn (T3, T12) |
| Compose sees earlier turns' facts (append reducer) and restates old values | Reset-marker reducer written by `load_session` each turn (T9); the ES two-turn test would show the old `card_options` fact otherwise (T12) |
| Import cycle: nodes need `GraphState` from `graph.py`, `graph.py` wires the nodes | `graph.py` top level holds only the types; `build_graph` imports the nodes inside its body (T9, T11). No `TYPE_CHECKING`-only imports in node signatures, since LangGraph reads node type hints at runtime |
| Reset marker breaks mypy (update type is not `list[Fact]`) | Marker is a `list[Fact]` subclass instance (e.g. `class ResetFacts(list[Fact])`, `RESET_FACTS`), recognized by `isinstance` in the reducer (T9) |
| Hint resolution over **all** cards (D12) makes `credit` ambiguous when a customer has an active and a closed credit card | As specified; the fixture's Closed card is a debit card so `credit` resolves on the multi-card customer and `last4:` proves the Closed-card rule (T5, T6). Visible in personas for the human (T12) |
| Committed `.mmd` differs from `draw_mermaid()` only by CRLF on Windows | Test compares after normalizing line endings (T11) |
| `.env` read from the wrong dir (`backend/` vs repo root) | `LLMSettings` reads `../.env` and `.env`, `extra="ignore"` (T2) |
| Sandbox against the 400k-row `products.csv` / 1097 transaction files is slow per call | FakeBank loads the bound customer's products once per instance; transactions are only queried by `search_transactions`, which no D1 flow calls (T5) |
| `make` / `uv` missing locally | Installed in T1 (Q1); `make` must be on Git Bash's `PATH` |
| "Green in CI" (B8) can't be checked: A3's CI isn't merged | Verifier reports it `UNVERIFIABLE` until A3 lands; local `pytest -q` is the proof today |
